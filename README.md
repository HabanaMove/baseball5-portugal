# Baseball5 Portugal — website inicial

Website estático, responsivo e multilingue (português, espanhol e inglês), preparado para publicação gratuita no GitHub Pages.

## Ficheiros

- `index.html` — conteúdo e estrutura da página.
- `styles.css` — design responsivo para telemóveis, tablets e computadores.
- `script.js` — seletor de idioma e menu móvel.
- `assets/favicon.svg` — ícone do site.

## Testar localmente

1. Descompacte a pasta.
2. Abra `index.html` num navegador.
3. Para uma experiência mais fiel, use um servidor local, por exemplo a extensão Live Server do Visual Studio Code.

A página usa Google Fonts quando há ligação à Internet; existem fontes alternativas no CSS.

## Publicar gratuitamente com GitHub Pages

1. Crie uma conta em https://github.com/ caso ainda não tenha.
2. Crie um repositório público, por exemplo `baseball5-portugal`.
3. Carregue os ficheiros e pastas deste pacote para a raiz do repositório. Não carregue apenas o ZIP.
4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/ (root)` e carregue em **Save**.
7. Aguarde a publicação. O endereço será semelhante a `https://o-seu-utilizador.github.io/baseball5-portugal/`.

A publicação pode demorar alguns minutos. O nome de utilizador e o URL final dependem da conta que criar.

## Antes de divulgar publicamente

- Confirme que o endereço de email e o WhatsApp de contacto estão corretos.
- Confirme a formulação institucional e a relação formal com federações, clubes e parceiros. O texto atual apresenta o site como projeto de desenvolvimento e não afirma uma afiliação oficial que não tenha sido verificada.
- Substitua a ilustração gráfica do campo por fotografias próprias ou por imagens com licença adequada, se desejar.
- Acrescente avisos de privacidade e cookies caso venha a integrar formulários, analítica ou outras ferramentas que recolham dados.
- Verifique as regras e a terminologia oficiais mais recentes da WBSC antes de publicar informação técnica detalhada.
- Não inclua logótipos de terceiros sem autorização.

## Limites desta versão

Esta é uma página institucional estática. Não inclui painel de administração, publicação automática de notícias, base de dados, autenticação, formulários guardados num servidor nem gestão de resultados. Contactos funcionam por email e ligação para WhatsApp. Essas funções podem ser acrescentadas posteriormente, usando serviços gratuitos com os respetivos limites.
